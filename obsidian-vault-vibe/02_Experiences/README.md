# 02 Experiences

Cada experiencia exportada desde Vibe debe quedar como una nota independiente.

Formato recomendado:

- Titulo claro.
- Fecha y hora.
- Grupo/persona.
- Lugar.
- Categoria.
- Eventos internos.
- Activos vinculados.
- Lectura humana.
- Aprendizajes.

Las experiencias no tienen que ser perfectas. Deben ser recuperables y enlazables.
