# Documentos

PDF, Word, TXT, CSV, JSON y otros documentos cargados como evidencia.

Regla de trabajo:

- preservar el documento original
- extraer texto cuando sea posible
- resumir en lenguaje claro
- enlazar con experiencias, eventos, hallazgos y publicaciones
- no convertir documentos sensibles en recomendaciones medicas, legales o financieras sin revision humana
