# 04 Assets

Referencias a activos multimodales.

Tipos:

- Imagen
- Video
- Audio
- Documento
- Biometria
- ZIP de transporte

Los videos no se incrustan aqui necesariamente. La nota debe conservar:

- Nombre del archivo.
- Experiencia o evento vinculado.
- Fecha/hora.
- Descripcion breve.
- Ruta o enlace si existe.
- Estado: pendiente, procesado, usado en publicacion.
