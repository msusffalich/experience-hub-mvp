# Videos

Videos vinculados a experiencias y publicaciones.

Uso recomendado:

- conservar el video como evidencia original
- crear una nota con resumen del contenido
- marcar los momentos importantes
- enlazarlo desde la experiencia, evento y publicacion correspondiente

Los videos no se incrustan siempre en el PDF final; cuando aplica, VibePWA puede generar un paquete con PDF, Markdown, manifest y carpeta `videos`.
