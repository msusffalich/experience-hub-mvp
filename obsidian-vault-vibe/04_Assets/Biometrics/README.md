# Biometria

Datos de Oura, Apple Health, relojes y otros wearables.

Esta carpeta es para notas interpretables, no para reemplazar el servidor.

Uso recomendado:

- guardar resumen por fecha o periodo
- registrar fuente: Oura, Apple Health, Samsung Health, Health Connect u otra
- mostrar datos observados: BPM, pasos, sueno, HRV, temperatura, recuperacion
- explicar impacto posible en energia, descanso y comportamiento
- evitar usar cero cuando una senal no existe; se marca como no disponible
