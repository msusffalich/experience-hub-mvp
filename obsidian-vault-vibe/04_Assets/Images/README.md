# Imagenes

Fotos, capturas, escaneos y piezas visuales vinculadas a experiencias.

Cada imagen deberia tener una nota breve con:

- experiencia relacionada
- evento relacionado, si aplica
- lugar y fecha
- personas o grupo
- descripcion humana de lo que muestra
- interpretacion generada por Vibe, si existe
- enlace al archivo original o copia local
