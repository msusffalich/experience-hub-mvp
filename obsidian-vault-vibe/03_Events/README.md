# 03 Events

Eventos internos dentro de experiencias largas.

Ejemplos:

- Llegada a un lugar.
- Reunion.
- Foto o video relevante.
- Conversacion importante.
- Medicion biometrica.
- Cambio de energia.

Cada evento debe apuntar a su experiencia madre.

Campos minimos:

- Experiencia:
- Hora:
- Lugar:
- Personas:
- Activos:
- Nota:
