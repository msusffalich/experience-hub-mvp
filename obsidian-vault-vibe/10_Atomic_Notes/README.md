# 10 Atomic Notes

Notas de una sola idea.

Regla tipo Karpathy:

- Una nota = una idea que vale recordar.
- Debe tener evidencia o ejemplo.
- Debe enlazar a experiencias concretas.
- Debe terminar con una pregunta o siguiente accion si aplica.

Ejemplo de titulo:

`La energia baja cuando el dia combina traslado largo y falta de sueno`

No copiar reportes completos aqui. Extraer patrones.
