# 00 Inbox

Aqui llegan notas nuevas sin procesar.

Regla simple:

- Si es una experiencia completa, mover a `02_Experiences`.
- Si es un evento interno, mover a `03_Events`.
- Si es una idea o aprendizaje, convertir en nota atomica en `10_Atomic_Notes`.
- Si es una salida final o borrador, mover a `40_Publications`.

No buscar perfeccion aqui. La funcion de Inbox es no perder nada.
