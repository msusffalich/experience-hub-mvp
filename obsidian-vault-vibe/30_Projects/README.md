# 30 Projects

Proyectos activos derivados de experiencias.

Ejemplos:

- Mejorar rutina de salud.
- Preparar viaje.
- Organizar material multimedia.
- Crear reporte para trabajo.
- Convertir experiencias en publicacion.

Cada proyecto debe tener:

- Objetivo.
- Estado.
- Experiencias relacionadas.
- Decisiones.
- Siguiente accion.
